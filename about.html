Arena Defender is a browser-based 3D survival shooter built around a simple question: how long can one pilot hold the line?

The project combines a focused Babylon.js arena with a modular JavaScript game system. The engine renders the world; the code decides what happens inside it.

Accounts, progress, and rankings are intentionally local to the browser. This prototype is designed as a complete coursework experience: playable, persistent, accessible, and ready to inspect.
